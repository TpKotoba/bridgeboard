# Valet｜橋牌賽事記分與管理

**從賽前編排、現場收分，到成績查詢與賽後檢討，在同一個網站完成。**

Valet 是繁體中文的橋牌賽事工具，適合橋藝社、俱樂部與小型賽事主辦方。支援隊制賽、雙人賽與 MiniBridge，裁判可以管理賽程和成績，賽員與觀眾則能用手機查看對戰、排名與逐副牌局。

雙人賽還可以讓搭檔掃描 QR Code，在自己的手機上輸入成績，由對手核對確認，再由裁判結算發布。從桌邊到成績表，減少紙本傳遞、重複抄寫與人工換算。

## 把辦賽時最花時間的工作接起來

| 辦賽時的問題 | Valet 能做的事 |
| --- | --- |
| 名單、賽程、牌型與成績分散在不同檔案 | 集中管理賽事與賽段，各賽段保有自己的名單、計分法與成績 |
| 收分後還要手算 IMP、VP 或重新整理排名 | 輸入合約與實得墩數，自動換算原始分、比較分與排名；更正後重新計算 |
| 不知道哪桌還沒交分、哪桌尚未核對 | 查看本圈收分進度與落後桌次；俱樂部收分另有對手確認流程 |
| 賽員一直詢問排名、對手與自己的成績 | 分享網站連結，讓大家自行查詢桌次、對戰、總排名與個別成績 |
| 想回顧一副牌，卻得另外找牌譜與分析工具 | 在逐副成績旁直接看四家牌型、雙夢家分析與互動試打 |
| 更正後說不清楚改了什麼 | 保留操作時間、原因及成績前後差異，方便追查與核對 |

## 賽前：準備名單、賽程與牌局

- **賽事與賽段管理**：一場賽事可設多個賽段，分別安排隊制或雙人賽、名單、牌數與計分方式。
- **直接選擇賽程編排**：依桌數與圈數提供適用的 Mitchell、完整 Howell、3/4 Howell 或全場同牌輪轉；預覽各圈桌次、方向與牌號後再套用。
- **知道要準備多少牌**：顯示牌組數、輪空與共牌需求，並計算不共牌時所需的完整牌套數。
- **匯入既有資料**：支援賽程編排 CSV、牌型 PBN，以及各圈時間區間 CSV；可先驗證與預覽。
- **產生隨機牌局**：在裁判後台產生 PBN，下載或套用到尚未收分的賽段。也可用 Deal Source 指定點力、牌型、花色長度或特定手牌，準備練習題。
- **MiniBridge 模式**：提供五種花色／無王搭配「一線、成局」的十種合約，採無身價計分，適合入門活動。

## 比賽中：讓收分、核對與排名連在一起

裁判或賽務可在後台選擇桌次與牌號，輸入合約、莊家、加倍與實得墩數，立即查看原始分。也能批次匯入成績 CSV，減少逐筆輸入。

| 比賽形式 | 計分與查看方式 |
| --- | --- |
| 隊制賽 | 開閉兩室比較、IMP 與 WBF 連續 20–0 VP；對戰收齊後換算 VP |
| 雙人賽 | MP、CrossIMP 或 ButlerIMP；兩種 IMP 計分可設定去頭去尾 |
| MiniBridge | 自動處理一線與成局門檻、超墩及宕墩，不需輸入線位與身價 |

**雙人賽俱樂部收分**讓每對搭檔使用專屬 QR Code 或連結：

1. 裁判指定當圈與輸入方。
2. 輸入方在手機提交本桌成績，另一方核對確認。
3. 確認後鎖定該桌成績，避免再次改動。
4. 裁判查看全圈進度，結算後對外發布成績。

需要處理例外時，可取消牌局、調整參賽者扣分，或對隊制賽設定不平衡合約，分別計算雙方的 IMP 與 VP。更正與判罰均留下操作紀錄；遇到同時更新，版本檢查會阻止舊資料直接覆蓋新資料。

## 賽員與觀眾：用手機找到自己關心的成績

- **總排名**：查看名次、得分與完成牌數，也能搜尋、追蹤參賽者。
- **輪次與對戰**：查詢各圈桌號、對手與牌號；雙人賽另顯示該圈開始前的累積成績。
- **隊伍／搭檔成績**：集中查看自己的逐副結果；隊制賽可切換圈次，查看雙方 IMP 與 VP 比數。
- **逐副比較**：比較各桌合約、實得墩數與得分，從同一副牌理解分數差異。
- **進度資訊**：進行中顯示本圈收分；結束後顯示有效成績與全部已收成績筆數。

一般成績頁每 30 秒自動更新，也可手動刷新。俱樂部收分模式則依裁判結算進度公開結果。

## 賽後：成績就是檢討的入口

公開牌型後，可以直接在逐副頁面查看四家手牌、HCP、Par Contract、LoTT 與雙夢家最佳墩數，並用出牌鍵盤試打、回退，觀察不同出牌的結果。

點擊一家姓名即可切換該家視角：首攻前只看自己的手牌，首攻後加上夢家手牌與本墩出牌。也能下載單副 PBN，或輸出至 Handviewer 繼續研究。

裁判可按牌組控制公開時間。成績、賽程、各圈時間及牌型都能匯出，另有賽事 JSON 匯出，方便留存與後續整理。

## 一場比賽怎麼開始？

1. **建立賽事**：填入名稱、日期、名單與計分方式；需要時設立賽段。
2. **準備賽程**：選擇或匯入賽程編排，核對桌次、牌號與所需牌套數。
3. **準備牌局**：匯入 PBN，或產生隨機牌局；設定牌型公開時機。
4. **開始收分**：使用後台、CSV，或啟用雙人賽手機收分。
5. **核對與發布**：查看缺分、處理更正與判罰，收齊後結束賽事。
6. **分享與檢討**：分享成績頁，公開適當牌型，下載資料保存。

## 本機試用

需要 Node.js 22 或較新的相容版本。在專案目錄執行：

```sh
npm ci
npm run dev:local
```

開啟 [http://127.0.0.1:3000](http://127.0.0.1:3000)，可使用內建模擬賽事熟悉操作。

| 本機角色 | 預設測試密碼 |
| --- | --- |
| 裁判 | `local-bridge-director-2026` |
| 賽務 | `local-bridge-admin-2026` |

以上為本機測試預設值；若已設定同名環境變數，則使用自行設定的密碼。本機資料保存在 `.data/events.json`。要讓其他人的手機連線，請部署到可存取的網站；`127.0.0.1` 只供本機使用。

## 自行部署與延伸

Valet 使用 Next.js、React 與 TypeScript，可部署至 Vercel，搭配 Neon PostgreSQL 保存賽事資料。

- [部署與備份](docs/deployment.md)
- [賽事與賽段](docs/competitions.md)
- [雙人賽手機收分流程](docs/club-mode.md)
- [賽程編排與 Deal Source 支援範圍](docs/movement-and-dealer.md)

目前每個賽段支援最多 32 組參賽者、15 圈與 128 副牌。雙人賽採單一比較組與合併排名；各賽段分別計分，不跨段累積。Swiss 自動配對、跨組 Neuberg 調整及離線送分尚未提供。Deal Source 支援常用發牌條件，未涵蓋完整 Dealer 語言，不支援的語法會明確提示。

開發檢查：

```sh
npm test
npm run typecheck
npm run build
```

雙夢家分析使用 [bridge-dds](https://github.com/bookchris/bridge-dds-js)；VP 換算依據 [WBF 連續 VP 公式](https://www.worldbridge.org/wp-content/uploads/2019/06/VP-Scale-Functiondetails.pdf)。
